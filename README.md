# OpenGL_Pong

> OpenGL + GLUT + OpenAL + GLMを使って実装した2人対戦Pongゲーム

## 概要

OpenGL/GLUTによる描画、OpenALによるサウンド、GLMによるベクトル計算を組み合わせてC++で実装したPongゲームです。
OpenGLの2D描画・当たり判定・音響処理の学習を兼ねて作成しました。

## 技術スタック

- 言語: C++
- グラフィックス: OpenGL、GLUT（glut32）
- 数学ライブラリ: GLM（ソース同梱）
- サウンド: OpenAL
- IDE: Visual Studio 2017（.slnファイルあり）
- 対象OS: Windows

## 機能

- 2人対戦プレイ（キーボード操作）
  - 1Pキー: W（上）/ S（下）
  - 2Pキー: I（上）/ K（下）
- ボールとパドル・壁の当たり判定
- パドルの当たり位置によるボール反射角度の変化
- スコア表示（先に11点取ったプレイヤーの勝利）
- センターラインの点線描画
- OpenALを使ったSE再生（パドル・壁接触時・得点時）
- 独自フォントシステムによるスコアHUD表示
- 任意キー押下でゲーム開始

## 使い方 / 動かし方

Visual Studioでソリューションファイル（`OpenGL_Pong.sln`）を開き、ビルド・実行してください。

```
OpenGL_Pong.sln をVisual Studioで開く
→ ビルド → 実行
```

- 起動後、任意のキーを押すとゲーム開始
- 1P: W/Sキー、2P: I/Kキーでパドルを上下移動
- Escキーで終了
